# ESP-Loader

Загрузчик прошивки в ESP32 для отладочной платы `Доска-H723`. Создает USB-Uart устройство.

## Установка и настройка

Прошивка линкуется в RAM_D1 контроллера STM32H723. Файл прошивки `ESPLoader.bin` кладётся на SD-карту в `/SD/utils/`, основная прошивка загружает его в память и запускает по команде `reboot esploader` в SSH или `rtos.reboot("esploader")` в Lua.
