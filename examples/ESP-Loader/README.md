# ESP-Loader

Мост USB-UART для прошивки модуля ESP32-C2 на отладочной плате `Доска-H723`.

## Установка и запуск

Прошивка линкуется в RAM_D1 контроллера STM32H723. Файл `ESPLoader.bin` кладётся на SD-карту в
`/SD/utils/`; основная прошивка по команде `reboot esploader` в SSH или `rtos.reboot("esploader")`
в Lua читает его, останавливает DMA и USB, копирует в RAM_D1, перезагружается и передаёт ему
управление до включения кэшей и MPU.

ESP-Loader переводит ESP32-C2 в загрузчик (ESP_EN, ESP_BOOT) и поднимает USB CDC
(VID 0483, PID 5740), который связан с UART7 модуля. Скорость берётся из настроек порта на ПК.
Загрузчик ESP включается один раз при запуске моста, линии DTR/RTS не передаются.

Прошивка модуля и команда esptool — в `AGENTS.md` (раздел «Прошивка»). Выход из моста — RESET.
