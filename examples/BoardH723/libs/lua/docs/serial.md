# Документация по библиотеке Serial для Lua

## Описание

Библиотека Serial предоставляет функциональность для работы с последовательными портами UART на микроконтроллере STM32H7xx. Она интегрирована с FreeRTOS и использует семафоры для синхронизации доступа к ресурсам.

## Объекты Serial

- `Serial` — UART2
- `Serial1` — UART3
- `Serial2` — UART5
- `Serial3` — USART1 (неактивирован по умолчанию)

## Методы объектов Serial

### begin(baudrate)
Инициализирует последовательный порт с заданной скоростью передачи данных.

**Аргументы:**
- `baudrate` (целое число) — скорость передачи данных, например 9600, 115200 и т.д.

### end()
Завершает работу последовательного порта, освобождает ресурсы.

### print(str)
Отправляет строку без символа перевода строки.

**Аргументы:**
- `str` (строка) — текст для отправки

### println([str])
Отправляет строку с добавлением символов `\r\n`.

**Аргументы:**
- `str` (опционально, строка) — текст для отправки

### write(data)
Отправляет байт или массив байтов.

**Аргументы:**
- `data` (число, строка или таблица) — данные для отправки

### available()
Возвращает количество доступных байтов в очереди приема.

### read()
Читает один байт из очереди приема. Возвращает `nil`, если данных нет.

### readBytes(length [, timeout])
Читает несколько байтов из очереди приема.

**Аргументы:**
- `length` (число) — количество байтов для чтения
- `timeout` (опционально, число) — таймаут в миллисекундах

### readString([timeout])
Читает строку до символа перевода строки или таймапута.

**Аргументы:**
- `timeout` (опционально, число) — таймаут в миллисекундах

## Примеры использования

```lua
-- Инициализация UART2 с скоростью 9600 бод
Serial:begin(9600)

-- Отправка строки без перевода строки
Serial:print("Привет")

-- Отправка строки с переводом строки
Serial:println(" Мир!")

-- Проверка наличия данных в очереди приема
if Serial:available() > 0 then
    -- Чтение одного байта
    local byte = Serial:read()
    print("Получен байт:", byte)
end

-- Чтение строки до символа перевода строки или таймаута (1 секунда)
local str = Serial.readString(1000)
print("Получена строка:", str)

-- Чтение 5 байтов с таймаутом (2 секунды)
local bytes = Serial:readBytes(5, 2000)
for i, b in ipairs(bytes) do
    print("Байт", i, ":", b)
end

-- Завершение работы UART2
Serial:end()
```

## Пины микроконтроллера STM32H7xx для UART

- **UART2**
  - TX: PA2 (AF7_USART2)
  - RX: PA3 (AF7_USART2)

- **UART3**
  - TX: PB10 (AF7_USART3)
  - RX: PB11 (AF7_USART3)

- **UART5**
  - TX: PB12 (AF14_UART5)
  - RX: PB13 (AF14_UART5)

- **USART1** (неактивирован по умолчанию)
  - TX: PB14 (AF7_USART1)
  - RX: PB15 (AF7_USART1)
