# Документация по библиотеке Lua для работы с I2C

## Описание
Библиотека предоставляет функционал для взаимодействия с устройствами по шине I2C. Поддерживает несколько портов I2C, включая настройку скорости и адреса устройства.

## Инициализация и завершение работы

### `Wire:begin([address], [speed])`
Начинает работу с I2C.
- **address** (опционально): адрес устройства по шине I2C (по умолчанию 0x50).
- **speed** (опционально): скорость передачи данных (по умолчанию 100 кГц). Доступные значения: `I2C100KHZ`, `I2C400KZ`, `I2C1MHZ`.

Пример:
```lua
Wire:begin(0x55, I2C400KZ)
```

### `Wire:end()`
Завершает работу с I2C.

Пример:
```lua
Wire:end()
```

## Отправка данных

### `Wire:write(address, data)`
Отправляет данные на устройство по указанному адресу.
- **address**: адрес устройства по шине I2C.
- **data**: строка или таблица с данными для отправки.

Пример:
```lua
local reg = {0x01, 0x00}
Wire:write(0x70, reg)
```

## Получение данных

### `Wire:read(address, length)`
Получает данные от устройства по указанному адресу.
- **address**: адрес устройства по шине I2C.
- **length**: количество байт для чтения.

Пример:
```lua
local recv = Wire:read(0xA0, 4)
if recv then
    print("Received:", table.unpack(recv))
end
```

## Пины

Для подключения к порту I2C4 используются следующие пины:
- **SCL**: PD12
- **SDA**: PD13

Для подключения к порту I2C1 используются следующие пины:
- **SCL**: PB8
- **SDA**: PB9

## Константы скорости

- `I2C100KHZ`: 100 кГц
- `I2C400KZ`: 400 кГц
- `I2C1MHZ`: 1 МГц

Эти константы можно использовать при инициализации I2C.

Пример использования констант скорости:
```lua
Wire:begin(0x55, I2C400KZ)
```

## Пример полного скрипта

```lua
-- Инициализация I2C с адресом 0x55 и скоростью 400 кГц
Wire:begin(0x55, I2C400KZ)

-- Отправка данных на устройство по адресу 0x70
local reg = {0x01, 0x00}
Wire:write(0x70, reg)

-- Получение 4 байт от устройства по адресу 0xA0
local recv = Wire:read(0xA0, 4)
if recv then
    print("Received:", table.unpack(recv))
end

-- Завершение работы с I2C
Wire:end()
```
